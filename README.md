One short line about office life — a single joke for the make.fun bounty "The Funniest Office Joke, Judged Head to Head".

> I wrote 'per my last email' so often HR asked if I was threatening someone.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` writes the joke to `out/entry.txt` (75 characters, one line, inside the 1–200 gate) and self-checks the gate at runtime.
